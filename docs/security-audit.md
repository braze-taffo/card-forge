# 源码敏感信息审计

初次整理：2026-11-07；上传前复核：2026-11-16。

检查了项目自有源码、部署脚本、文档、Git 历史，以及被忽略的构建输入和输出。额外核对了本机实际生产凭据是否出现在待分享文件中；检查过程不输出凭据值。

## 发现与处理

- 未发现真实 API 密钥、管理员密码、控制令牌或私钥。密钥格式命中为示例占位符、测试数据或第三方 CSS/标识符，已逐类复核。
- 旧部署脚本和交接记录中存在真实服务器地址、主机别名、个人本机路径和生产运维细节。实际配置、原始交接资料、发布记录和运维脚本已移至项目外的受限目录，目录权限 0700、文件权限 0600。
- 项目只保留通用部署模板和必要构建工具；文档改为通用说明，真实服务器连接信息不随源码分发。
- Git 历史同步清理上述文件与身份路径，并清除旧引用、reflog 和不可达对象；原始恢复备份单独存放在项目外的私有目录。
- 增加 `npm run audit:sensitive` 和更多敏感文件忽略规则，用于检查后续变更。

公开产品链接、依赖仓库/CDN、localhost、回环监听地址和专用于文档的示例地址保留。第三方网络过滤代码中的私网范围属于安全规则，不是实际内部站点；未破坏这些规则或修改公开许可证。

生产运行配置保留在服务器原位置。此次处理只涉及源码整理目录及其 Git 数据，不修改运行中的网站或模型密钥。

## 复查

```bash
npm run audit:sensitive
npm run check
npm run build
npm test
```

仓库内扫描器是常见格式和地址的回归检查，不替代完整内容审阅。原始运维资料、备份和交接归档不得作为源码项目附件直接公开。

## 上传版本

本次发布从最新源码建立独立 Git 仓库，包含原项目未提交的长文提炼修改和对应测试。旧 Git 历史、构建产物、本地测试记录、截图、小说原文、数据库和运行配置均不进入上传仓库。

上传前使用 Gitleaks 8.30.1 独立扫描原项目完整 Git 历史和发布目录，并运行项目自身的敏感信息扫描。另在本机读取实际部署配置，将其中的凭据与发布文件逐一比对；过程不输出密钥、密码或控制令牌的值。公开产品链接、官方 API 地址、公开社群入口和第三方许可证保留。

忽略规则补充了管理员认证文件、服务账号、浏览器 cookie、网络请求归档、数据库转储、Git bundle 和压缩归档。真实凭据仍须通过本地配置或环境变量提供。
